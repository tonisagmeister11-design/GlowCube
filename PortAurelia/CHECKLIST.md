## Known limitations (honest)

* The Windows executable could not be launched in this Linux environment (no Windows/Wine).
  The identical pack layout is verified by the Linux smoke test; the EXE structure (PE +
  embedded core pack) is checked.
* Rendering was verified with a software Vulkan rasterizer (~1–2 FPS). Real-GPU frame rates
  are not measured; draw calls/primitives are reported above.
* Aircraft and boats are static props (not drivable); there is no police helicopter.
* Only four interior types are enterable; other buildings are exteriors.
* Voices are synthetic vocal sounds (pain, screams, shouts); dialogue is shown as subtitles.
* The release ZIP (≈134 MB) is too large for a git file (GitHub limit 100 MB); it is produced by
  `Tools/Export/build_release.py` locally or by the CI workflow `.github/workflows/port-aurelia.yml`.
