# Harbor Heat

Standalone 3D open-world action game for Windows (64 bit) set in the fictional coastal metropolis of Port Aurelia.
Built with a portable **Godot 4.4.1** runtime (GDScript, Forward+, Jolt physics) and a fully
procedural **Blender (bpy)** asset pipeline. Every asset — city, buildings, characters,
vehicles, weapons, props, interiors, textures, sounds, UI and logo — is generated by the
scripts in this repository. No third-party game assets are used, and the game ships **without
music** (players can drop their own files into `Audio/Music/`).

```
Download ZIP → extract → StartGame.exe → start screen → play
```

---

## 1. Quick start (developers)

```bash
Tools/setup_toolchain.sh          # Windows: Tools\setup_toolchain.ps1
Tools/build_all.sh                # assets → import → validation → tests → Windows builds
```

Results:

| Output | Content |
|---|---|
| `Export/Release/MyOpenWorldGame/` | release build (no debug tools) |
| `Export/Release/MyOpenWorldGame.zip` | the downloadable game |
| `Export/Development/MyOpenWorldGame/` | development build (console window, F1–F11 debug tools) |

Open the project in the editor: `Tools/Godot/Godot_v4.4.1-stable_linux.x86_64 --path Game -e`
(self-contained mode: editor settings and export templates live in `Tools/Godot/editor_data`).

## 3. Game architecture

* **Event bus** (`core/events.gd`): systems communicate through signals (crimes, gunshots,
  money, missions, UI messages) instead of hard references.
* **GameWorld** (`world/world.gd`) boots the static data (city plan, road graph, sidewalk graph,
  props), streaming, sky and ocean, spawns the player and instantiates the gameplay systems
  listed in `GameWorld.SYSTEMS`; each system registers itself (`GameWorld.instance.traffic`, …).
* **Streaming**: 215 chunks of 200 m, LOD0 ≤ 260 m, LOD1 beyond, far HLOD for everything not
  loaded, props as MultiMeshes with visibility ranges, lamp light pool, occluders.
* **AI**: traffic follows lane graphs with signals, stop signs, gaps, lane changes, sirens and
  panic; pedestrians walk sidewalk graphs, cross at signals, sit, talk, phone, flee, cower,
  fight and use cover; police units drive emergency routes, pursue, deploy officers, build
  roadblocks and search the last known position. Far agents run in cheap kinematic mode.
* **Saves**: `Saves/slot_1..3.json`, `Saves/autosave.json`; settings in `Config/settings.cfg`.
  In the release build these folders sit next to `StartGame.exe` (portable).

## 4. Blender / asset pipeline

All scripts run with the bpy venv (`Tools/Blender/venv/bin/python`) or `blender -b -P`.

| Script | Purpose |
|---|---|
| `generate_city.py -- --plan` | city plan (citygen) + all 215 chunk GLBs + far HLOD |
| `generate_roads.py` | roads, intersections, roundabouts, bridges, ramps, tunnels, markings, blocks, lots |
| `generate_buildings.py` / `generate_towers.py` | styled buildings, skyscrapers, all landmarks |
| `generate_vegetation.py`, `generate_lights.py`, `generate_props.py` | trees, lamps, traffic lights, street furniture |
| `build_asset_library.py` | props library GLB + metadata for MultiMesh placement |
| `generate_vehicles.py` + `_carbody.py` | 16 vehicles: high-res lofted bodies (flared arches, crease, raked nose), shader-drawn panel gaps, flush projected lamps/grilles/plates, alloy wheels, full interiors, detachable bumpers |
| `generate_weapons.py` + `_shapes.py` | 8 high-detail weapons (~34k tris) with chamfered edges, edge-wear/AO vertex colours, muzzle metadata |
| `generate_characters.py` + `_anatomy.py` | anatomical humans from implicit muscle primitives (2 body types, hands with fingers, detailed faces, eyelids, iris), body zones hidden under clothing, 30+ outfit meshes, 34 animations |
| `generate_interiors.py` | safehouse, store, gun shop (shooting range), bank |
| `setup_materials.py` | material names/previews · CLI: validates every GLB material has a Godot material |
| `setup_uvs.py` | UV conventions · CLI: validates UV0/UV2 against the shaders |
| `generate_lods.py` | LOD chain + far HLOD · CLI: LOD report |
| `generate_colliders.py` | collision surfaces · CLI: validates chunk collisions |
| `export_glb.py` | GLB export · CLI: size/triangle summary |

Godot side: `tools/import/scene_post_import.gd` replaces materials by name with
`assets/materials/*.tres`, sets LOD visibility ranges and turns `Col_<surface>-colonly` meshes
into static bodies tagged with their surface (footsteps, tyre grip).

Other generators: `Tools/Textures/generate_textures.py` (PBR-ish tiling textures),
`Tools/Materials/build_materials.py` (94 shader materials), `Tools/Audio/generate_sfx.py`
(83 sound effects, no music), `Tools/Map/render_map.py` (map/radar texture).

## 5. Controls

| Action | Keyboard / Mouse | Controller (Xbox layout) |
|---|---|---|
| Move / look | WASD / mouse | left / right stick |
| Sprint / jump / crouch | Shift / Space / Ctrl | A / X / left stick click |
| Aim / shoot / reload | RMB / LMB / R | LT / RT / B |
| Weapons | 1–9, mouse wheel, hold TAB for the wheel | hold LB (wheel), D-pad left |
| Cover | Q | RB |
| Interact / enter vehicle | E / F | D-pad right / Y |
| Map / phone / pause | M / ↑ / ESC | D-pad down / D-pad up / Start |
| Camera mode / look back | V / B | Back / right stick click |
| Drive | W/S, A/D, Space handbrake, H horn, L lights, G siren | RT/LT, left stick, RB, left stick click, D-pad right |
| Quick save | F5 | – |

### Camera

`V` (controller: Back) cycles the camera: on foot third person ↔ first person, in vehicles
chase near → chase far → hood → cockpit (first person). Defaults, distance, height, FOV, shake,
auto-centring, head bob, crosshair, minimap and HUD are in **Einstellungen → Kamera**.

### Performance mode (Einstellungen → Grafik → Leistungsmodus)

| Mode | What it does |
|---|---|
| Aus | full Forward+ graphics according to the individual settings |
| Ausgewogen | 80 % 3D resolution with FSR, quality/effects capped at medium, simple shadows, smaller sky reflections, ~80 % pedestrians/traffic |
| Maximal | for weak laptops: **OpenGL (Compatibility) renderer** after a restart, 60 % 3D resolution, no shadows/SSAO/SSR/glow, near view distance, aggressive LODs, no skin/cloth micro detail, ~55 % pedestrians/traffic, reduced explosion detail, 30 FPS cap (saves power) |

The renderer can also be chosen manually (Forward+, Mobile, Compatibility). Exported builds
store the choice in `override.cfg` next to `StartGame.exe`; Godot applies it at start-up. If
Vulkan is unavailable the game falls back to OpenGL automatically.

## 6. Debug controls (development build only)

F1 overlay (FPS, position, chunk, AI counts) · F2 spawn vehicle · F3 spawn pedestrian ·
F4 all weapons/armour/money · F6 wanted level · F7 teleport to waypoint/next POI ·
F8 complete/start mission · F9 toggle AI · F10 performance monitors · F11 +3 h (Shift: weather)

## 7. Tests

Headless, each prints `PASS/FAIL` lines and exits non-zero on failure:

```bash
G=Tools/Godot/Godot_v4.4.1-stable_linux.x86_64
for t in gameplay traffic ped police economy mission interior flow; do
  $G --headless --path Game res://tests/${t}_test.tscn; done
```

Screenshot scenes (need a GPU or `xvfb-run` + Vulkan): `street_shot` (`--perf 0..2`), `ui_shots`,
`interior_shots`, `character_viewer`, `vehicle_viewer` (`--closeup id,id`), `weapon_viewer`,
`explosion_shots`, `demo_shots` (`--views 1`: hood, cockpit and first-person shots), `world_viewer`.

## 8. Release build

`python3 Tools/Export/build_release.py` writes `Game/export_presets.cfg` and produces:

```
MyOpenWorldGame/
├─ StartGame.exe          Windows x86_64, embedded core pack (code, UI, shaders, materials)
├─ Game/HarborHeat.pck   characters, vehicles, weapons, props, interiors, textures, sounds
├─ Assets/City.pck        city chunks, far city, map, city data
├─ Audio/Music/           your own music (optional, disabled by default)
├─ Saves/  Config/        portable save games and settings
└─ LIES_MICH.txt
```

`Paths` mounts the two data packs before anything is loaded. `--smoke` builds a Linux binary
with the same layout and boots it headless (`-- --smoke-test`) to verify the packaging.
